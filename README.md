## Aronno Keyboard
**Aronno Keyboard** is a lightweight, privacy-focused keyboard designed for seamless Bengali and English typing.

### Visual & UI Updates
*   **Redesigned Settings**: Keymap and Phonetic Tutorial pages now feature a sleek Material Design with card-based layouts and improved typography.
*   **Dynamic Status Bar**: Status bar color now adapts to your system theme (Red for Dark Mode, Green for Light Mode).
*   **Unified Spacing**: Consistent 20dp margins across the Homepage and setup screens for a polished look.

### Fixes
*   **Homepage Navigation**: Resolved unresponsive buttons on the homepage for smoother navigation.
*   **Text Rendering**: Fixed issues with Bengali dependent vowels in tutorial examples using refined text rendering logic.
